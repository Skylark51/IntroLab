# IntroLab

Computational/bioinorganic chemistry literature research assistant.

IntroLab v0.1 is a lightweight, local-first Python CLI that records journal-by-journal literature searches, verifies Crossref DOI metadata, tracks claims and source evidence, and exports research context and a ChatGPT web-research prompt.

**Status:** experimental research scaffold. Crossref metadata is not evidence that a mechanistic assertion is supported. Publisher/source verification and post-publication novelty checks require researcher review.

See [README_KO.md](README_KO.md) for Korean setup and usage, and [IMPLEMENTATION_PROMPT.md](IMPLEMENTATION_PROMPT.md) for the full development prompt.

Requires Python 3.10+; no pip packages or API keys for core features.
